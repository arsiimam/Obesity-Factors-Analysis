# Obesity Factors Analysis

## Project Overview
This project aims to analyze the factors contributing to obesity levels based on eating habits and physical conditions. Using statistical techniques, we will explore the relationships between various lifestyle choices and obesity to derive meaningful insights that can help in obesity prevention and management.

## Dataset Overview
The dataset used in this project is the **Estimation of Obesity Levels Based on Eating Habits and Physical Condition** from the UCI Machine Learning Repository. It contains multiple features related to dietary habits, physical activity, and body measurements.

| Column Name      | Description                                             | Data Type |
|-----------------|---------------------------------------------------------|-----------|
| Gender         | Gender of the individual                                | Categorical |
| Age            | Age of the individual                                  | Numeric |
| Height         | Height in meters                                       | Numeric |
| Weight         | Weight in kilograms                                   | Numeric |
| FCVC           | Frequency of consumption of vegetables                 | Numeric |
| NCP            | Number of main meals per day                           | Numeric |
| CH2O           | Daily water intake                                    | Numeric |
| SCC            | Consumption of caloric food (Yes/No)                   | Categorical |
| FAF            | Physical activity frequency per week                   | Numeric |
| TUE            | Time spent using technology devices                    | Numeric |
| CALC           | Frequency of alcohol consumption                        | Categorical |
| MTRANS         | Mode of transportation                                  | Categorical |
| NObeyesdad     | Obesity level category                                 | Categorical |

## Source
- [UCI Machine Learning Repository: Obesity Levels Dataset](https://archive.ics.uci.edu/dataset/544/estimation+of+obesity+levels+based+on+eating+habits+and+physical+condition)
